# Bulk URL Opener — 仕様書（確定版）

## 1. 概要
ブラウザーツールバーから開くポップアップ内に、複数URLを貼り付けて一括で新規タブを開くChrome拡張（Manifest V3）。URLは改行またはカンマで区切ればよく、追加機能や将来拡張は持たせない。

## 2. 対象範囲
- ブラウザ: Google Chrome (MV3 対応ブラウザ含む)
- UI: 拡張機能の `action` ポップアップのみ
- 権限: `tabs`（新規タブ作成のため）

## 3. ユースケース
1. ユーザーが情報収集時に得たURLをまとめて開きたい
2. スプレッドシートやメモアプリからURLリストをコピーして貼り付け
3. 実行ボタンを押すと順番にタブが開き、完了メッセージで件数を把握

## 4. 機能要件
- 入力テキストエリア
  - `placeholder`: 「改行やカンマ(,)区切りで入力」
  - 受け付ける区切り文字: 改行、カンマ
  - 受理上限: 30件（ソフト制限。超過時はエラーメッセージ）
- URL正規化
  - 先頭にスキームが無い場合は `https://` を補完
  - `new URL()` で検証し、`http` または `https` 以外は破棄
  - 空行・重複URLは除外
- タブ生成
  - `chrome.tabs.create({ url, active: false })`
  - 順番にawaitし、ブラウザ負荷とレート制限を緩和
- ステータスメッセージ
  - 成功時: 「N件のタブを開きました。」
  - 失敗時: 処理を中断し「タブの作成に失敗しました…」
  - 入力不足/上限超過時: 適切なバリデーションメッセージ
- クリアボタン
  - テキストエリアとステータスのリセット

## 5. 非機能要件
- UI応答時間: 入力やボタン操作で100ms以内の反応
- 堅牢性: `chrome.tabs` が無い場合はエラーフィードバック
- プライバシー: 外部通信なし、保存データなし
- アクセシビリティ: `aria-live="polite"` でステータスを通知

## 6. ファイル構成
- `manifest.json`: MV3設定 (action popup, tabs権限, default_locale)
- `popup.html`: UIレイアウトと静的テキスト
- `styles.css`: モダンでシンプルなスタイリング
- `popup.js`: 入力解析・バリデーション・タブ制御
- `_locales/{ja,en}/messages.json`: Chrome Web Store説明文
- `icons/`: 16/32/128px PNG
- `docs/design.md`: 本ドキュメント
- `docs/TESTING.md`: 手動検証ガイド
- `README.ja.md`, `README.en.md`: 製品説明（JA/EN）

## 7. 制限事項
- 30件を超えるURLは一度に処理できない
- URLエンコードやパラメータ補完など高度な整形は行わない
- 選択したタブを自動でアクティブ化したり、既存タブを再利用しない
- Chromeのタブ上限や各サイトの自動アクセス制限の影響を受ける

## 8. 受け入れ条件
- 改行とカンマの両区切りで同一の結果を得られる
- 無効な入力のみの場合はタブを開かずにエラー表示
- 正常時に順番どおり `chrome.tabs.create` が呼ばれる
- UIテキスト/コメント/ドキュメントが日本語で提供されている
- README.ja/README.en がともに存在し、内容が同期している
