# テストガイド — Bulk URL Opener
Chrome の手動検証で要件をカバーするための手順をまとめます。

## 前提条件
- Google Chrome (最新安定版)
- `bulk-url-opener` フォルダを「パッケージ化されていない拡張」として読み込み済み
- ブラウザーツールバーにアイコンが表示されている

## シナリオ一覧
| ID | シナリオ | 手順 | 期待結果 |
|----|-----------|------|-----------|
| AC-1 | 単純な改行区切り | `https://example.com` と `https://openai.com` を改行で入力し実行 | 2タブが非アクティブで追加され「2件のタブを開きました。」と表示 |
| AC-2 | カンマ区切り | `https://news.ycombinator.com, https://github.com` を1行で実行 | 2タブが開き成功メッセージ |
| AC-3 | スキーム補完 | `example.com` と `www.google.com/maps` を入力 | `https://` が補完されタブが開く |
| AC-4 | 無効行フィルタ | `not-url` や空行のみを入力 | エラー表示「URLを正しく入力してください。」でタブは開かれない |
| AC-5 | 目安の件数を超える | 31件の有効URLを入力 | 31タブが開く。30件は入力欄の下の目安の表示だけで、実行は止めない |
| AC-6 | 途中失敗 | `https://example.com` + `chrome://settings` を入力 | http/https以外は除外され、残りのみが開く（1件）。|
| AC-7 | クリアボタン | 入力とステータスを持つ状態で「クリア」 | テキストボックスとメッセージが空になる |

## 追加チェック
- ステータスメッセージが `aria-live="polite"` によりスクリーンリーダーへ通知されること
- `chrome.tabs` が利用できない環境（テストツール等）ではエラー表示が出ること
- `_locales` の説明文がChrome拡張の詳細画面に反映されること（`chrome://extensions` → 詳細 → 「説明」）

## トラブルシューティング
- 何も起きない場合: デベロッパーツールのConsoleでエラーを確認、`chrome.tabs` 権限が付与されているか確認
- ボタンが操作不能の場合: 直前にエラーが出ていないか、ポップアップを閉じて再表示する
- 多数タブが必要な場合: ブラウザが処理しきれない場合があるため、分割実行を推奨
